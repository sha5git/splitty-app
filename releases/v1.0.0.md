## Release notes

First production release of **Splitty**, a shared expense tracker for groups. Deployed at [splitty.shashankdev.com](https://splitty.shashankdev.com).

### Features

**Authentication**
- Email/password sign-up and login via Firebase Auth
- Protected app shell; API secured with Firebase ID token verification

**Groups & members**
- Create groups and add members by email
- Group list with per-user net balance summary cards

**Expenses**
- Add group expenses with equal splits among selected members
- View and delete expenses

**Balances & settlements**
- Per-member balance breakdown within a group
- Simplified debt view (greedy minimization of transactions)
- Record settlements between members

**Frontend**
- React + Vite SPA with TanStack Router and React Query
- Group detail tabs: Expenses, Balances, Settlements, Members
- INR currency formatting, light/dark theme with persisted preference
- Responsive UI built with Tailwind CSS and shadcn-style components

**Backend**
- Spring Boot REST API with PostgreSQL and Flyway migrations
- OpenAPI specification for the Phase 1 API surface
- Balance calculation service with unit tests

### Infrastructure

- GitHub Actions **CI** workflow: verifies backend and production frontend build on every push to `main`
- GitHub Actions **Release** workflow: semver tags (`v*`) publish `splitty-deploy.tar.gz` for Termux deployment
- Production Firebase project (`splitty-app-termux`) separate from local development
- Termux deployment scripts (`deploy.sh`, `start-all.sh`) for download-and-run updates without on-device builds

### Known limitations (v1.0.0)

- Equal splits only (no custom or percentage splits yet)
- Email-based member lookup only
- Single-server Termux hosting (personal/demo scale)
