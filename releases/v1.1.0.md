---

## Release notes

Feature release for **Splitty** with a denser mobile expenses experience, full expense edit/delete flows, and group rename.

### Features

**Expenses**
- Month-grouped expense list with date column and personal you lent / you borrowed amounts
- Tap an expense to open a detail page with payer, splits, and balance impact
- Edit expenses (description, amount, payer, split members) via the same form as add
- Delete expenses from the detail page with confirmation

**Groups**
- Rename a group from the group detail header (pencil icon)

**API**
- `GET /api/expenses/{id}` — fetch a single expense
- `PUT /api/expenses/{id}` — update expense (preserves original date; rebuilds equal splits)
- `PUT /api/groups/{id}` — update group name

**Backend / quality**
- `ExpenseServiceTest` and `GroupServiceTest` for get/update flows
- Hibernate SQL query logging disabled in default config

### Known limitations (unchanged from v1.0.0)

- Equal splits only (no custom or percentage splits yet)
- Email-based member lookup only
- Single-server Termux hosting (personal/demo scale)
