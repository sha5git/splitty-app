## Release title

**Splitty v1.2.0 — Settlements on the expenses timeline**

---

## Release notes

Feature release for **Splitty** that folds settlements into the expenses experience, makes recording payments faster from balances, and adds settlement correction.

### Features

**Expenses**
- Removed the separate **Settle** tab; group detail is now **Expenses | Balances | Members**
- **Settle** button next to **Add expense** opens a record-payment dialog (From, To, Amount)
- Settlements appear in the same month-grouped timeline as expenses, with a ₹ icon and “X paid Y ₹…” copy
- Tap a settlement row to **edit** payer, recipient, and amount (fixes mistaken amounts such as ₹2500 vs ₹250)

**Balances**
- Shows only **your** outstanding balances (no longer falls back to everyone else’s debts when you’re settled up)
- Tap a balance row to open the settlement dialog prefilled with that debt’s From, To, and Amount
- **Record a settlement** button still available for manual entry

**API**
- `PUT /api/settlements/{id}` — update settlement (preserves original date; recalculates balances)

**Backend / quality**
- `SettlementServiceTest` for update flows and validation
- OpenAPI spec updated; frontend types regenerated

### Fixes

- Balances tab no longer shows other members’ debts when the logged-in user has no outstanding balance

### Known limitations (unchanged from v1.1.0)

- Equal splits only (no custom or percentage splits yet)
- Email-based member lookup only
- Single-server Termux hosting (personal/demo scale)
