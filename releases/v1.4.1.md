## Release notes

Patch release for **Splitty**. New accounts keep the **Full name** from signup (for example **Shashank**) instead of appearing as `User` plus a long Firebase uid.

### Fixes

- Wait for Firebase `updateProfile` (and a fresh ID token) before the first `/api/users/me` call, so the backend does not create the user before `displayName` exists
- If a token still has no name, store a capitalized email local-part (`shashank@…` → **Shashank**) instead of `User <uid>`
- On the next login, replace an existing `User <uid>` name when a better name is available
- Local `reset-db.ps1` also clears `user_fcm_tokens`

### After deploy (fresh start)

If you are wiping prod data: truncate app tables (including `user_fcm_tokens` and `users`), delete Firebase Auth users, **then** sign up again on this build.

```bash
~/splitty/deploy.sh v1.4.1
~/splitty/start-all.sh
```
